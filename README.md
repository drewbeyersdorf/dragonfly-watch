# dragonfly-watch
A sentry that sees almost everything at once and intercepts what moves wrong: motion-triggered review, not blanket surveillance.
- Animal behavior: dragonfly compound vision and interception - near-360-degree awareness, predictive intercept paths, very high catch rate on chosen targets.
- Fleet mechanism: anomaly watch over the whole board. The watcher flags only what deviates; everything else passes unlogged. Attention is spent like a budget.
Status: private staging. Part of the HERDR animal-harness series.
